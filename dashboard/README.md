# RUDRA — Dashboard

A small web view to watch RUDRA: online devices, live bus traffic, and logs.

Phase 0 is a static placeholder (`index.html`). In Phase 7 it connects to the
brain (WebSocket / MQTT-over-WebSocket) for a live feed, and can later adopt the
look of RD-Portal.

```bash
# preview the placeholder
npx serve dashboard      # or just open dashboard/index.html
```
